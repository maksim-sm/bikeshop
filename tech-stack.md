# Технологический стек

Стек выбран под первую версию из `design-document.md`: один магазин, каталог на несколько тысяч товаров, гостевой заказ, личный кабинет и простая админка. Отдельных сервисов, поискового движка и мобильного приложения нет.

## Приложение

**Next.js (TypeScript, App Router) и React.**

Один проект закрывает витрину, оформление заказа, личный кабинет и админку. Серверный рендеринг отдаёт каталог и карточку сразу, без отдельного API. Адаптивная вёрстка на Tailwind CSS закрывает телефон и компьютер.

Админка — те же страницы под маршрутом `/admin`. Доступ только у пользователя с ролью менеджера.

## Данные

**PostgreSQL.**

Товары, размеры рам, остатки, корзина и заказы — связанные таблицы. Несколько тысяч товаров фильтруются обычными индексами по типу, бренду, цене и наличию. Поиск по названию и бренду — `ILIKE` с индексом `pg_trgm`. Отдельный поисковый сервис не нужен: требование — ответ за одну-две секунды.

Цена фиксируется в строке корзины в момент добавления. При оформлении сервер ещё раз проверяет остаток и отказывает, если товара уже нет.

Фото хранятся в S3-совместимом хранилище. В базе лежит только ссылка.

Схема и запросы — **Prisma**. Миграции ведут таблицы товаров, заказов и пользователей.

## Корзина, вход и заказы

Корзина живёт в базе и привязана к cookie-сессии. Гость оформляет заказ без аккаунта. После входа та же корзина привязывается к пользователю.

Регистрация — email и пароль. Она нужна только для истории заказов. Сессии и роли — **Auth.js**.

Письмо с номером и составом заказа уходит через SMTP магазина. Отдельный маркетинговый сервис рассылок не нужен.

## Оплата

Интеграции с платёжной системой в этой версии нет. Заказ оформляется с оплатой при получении и сразу получает статус «принят». Онлайн-оплата картой добавляется отдельным шагом, когда будет выбран провайдер. Данные карты магазин не хранит и в этой версии не принимает.

## Метрики

События первой версии пишутся в ту же базу: просмотр карточки, добавление в корзину, начало оформления, заказ. Доли из раздела 10 PRD считаются SQL-запросом. Число заказов за неделю — выборка по таблице заказов в админке. Отдельная аналитическая система не входит в первую версию.

## Запуск

Один процесс Node.js и управляемый PostgreSQL. Этого достаточно для каталога и админки одного магазина.
