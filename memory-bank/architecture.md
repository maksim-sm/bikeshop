# Архитектура файлов

Документ описывает, за что отвечает каждый файл. После шага, который добавляет, удаляет или переносит файл, роль здесь обновляется в том же изменении.

Кода приложения ещё нет. Ниже сначала перечислены существующие документы, затем целевое размещение файлов из `implementation-plan.md`. Новые файлы класть только в эти места.

## Документы

| Файл | Роль |
| --- | --- |
| `memory-bank/design-document.md` | Что делает магазин: экраны, заказ, кабинет, админка, качество и метрики. |
| `memory-bank/tech-stack.md` | Чем это делается: Next.js, PostgreSQL, Prisma, Auth.js, хранилище фото, SMTP. |
| `memory-bank/ai-rules.md` | Правила реализации: объём, цена, остаток, доступ, проверка сценария. |
| `memory-bank/implementation-plan.md` | Порядок шагов и тест, которым шаг закрывается. |
| `memory-bank/progress.md` | Какие шаги плана уже пройдены и чем подтверждён тест. |
| `memory-bank/architecture.md` | Роль файлов проекта. |
| `README.md` | Короткое имя репозитория. Остаётся в корне. |

## Приложение

Корень репозитория — один проект Next.js (TypeScript, App Router, Tailwind CSS).

| Файл | Роль |
| --- | --- |
| `package.json` | Зависимости и команды запуска, сборки и проверки. |
| `tsconfig.json` | Настройки TypeScript. |
| `next.config.ts` | Настройки Next.js. |
| `app/layout.tsx` | Общая оболочка страниц и русский язык документа. |
| `app/globals.css` | Подключение Tailwind. |

Страницы только отображают данные и принимают действия. Запросы к базе, цена, остаток и права живут в серверных модулях, не в клиентских компонентах.

## Серверные модули

| Файл | Роль |
| --- | --- |
| `lib/db.ts` | Единственный экземпляр клиента Prisma. |
| `lib/catalog.ts` | Чтение каталога, карточки, фильтров, сортировки и поиска. |
| `lib/money.ts` | Перевод копеек в цену для экрана. |
| `lib/cart.ts` | Сессия корзины, строки, фиксация цены, объединение при входе. |
| `lib/orders.ts` | Транзакция заказа: проверка остатка, списание, номер, статус, счётчик продаж. Отмена возвращает остаток, выход из отмены списывает его снова. Заказ гостя хранится без пользователя. |
| `lib/mail.ts` | Письмо о заказе через SMTP. Ошибка отправки не отменяет заказ. |
| `lib/auth.ts` | Регистрация, вход и роль через Auth.js. |
| `lib/uploads.ts` | Загрузка фото в хранилище и возврат ссылки. |
| `lib/metrics.ts` | Запись событий визита и расчёт долей. |
| `app/admin/layout.tsx` | Допуск в админку только роли менеджера. |

## Данные

| Файл | Роль |
| --- | --- |
| `prisma/schema.prisma` | Схема товаров, вариантов, фото, корзины, заказов, пользователей и событий. |
| `prisma/migrations/` | История миграций. Схему менять только новой миграцией. |
| `prisma/seed.ts` | Повторяемый начальный набор товаров и один менеджер. |
| `.env` | Адрес базы, секрет сессий, SMTP и параметры хранилища фото. В репозиторий не класть. |
| `.env.example` | Имена переменных без секретов. |
